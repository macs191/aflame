أنت مهندس Full-Stack Senior ومكلف ببناء منصة عربية لبث الفيديو. المطلوب منصة عربية كاملة لعرض قنوات مباشرة، أفلام، ومسلسلات باستخدام روابط HLS بصيغة m3u8 يملك صاحب المنصة حق استخدامها. استخدم ستاك حديث: React + Vite + TypeScript + Tailwind للفرونت إند، Node.js و Express للباك إند، وFirebase للـ Database. الواجهة عربية بالكامل RTL بتصميم Dark/Gold و بطاقات زجاجية وأنيميشنز هادئة. أنشئ صفحات: الرئيسية، بث مباشر، أفلام، مسلسلات، تواصل، مفضلة، سجل مشاهدة، وحساب وصفحات إدارة للمسؤول. بنظام اشتراكات، مصادقة Firebase، و Firestore Security Rules صارمة تمنع وصول غير مصرح. استخدم متغيرات البيئة و هيكل مشروع منظم. قواعد جودة الكود: استخدم TypeScript strict، مكونات قابلة لإعادة الاستخدام، معالجة أخطاء، حالات تحميل، تصميم متجاوب، وحماية للـ API. واجهة المستخدم تجربة سلسة مع رسائل عربية واضحة. أضف تحميل كسول للصور، تقسيم صفحات، وحماية للمسارات، ونظام صلاحيات واضح. استخدم StreamProvider طبقة منفصلة علشان لو مزود البث تغيّر مستقبلاً ما نكسرش النظام. رابط البث صمّمه ليكون قابل للتحديث دون افتراض واحد. وابدأ تنفيذ المراحل بالترتيب: إعداد المشروع، ثم Firebase والمصادقة، فالنماذج قاعدة البيانات، فالموقع العام، فالمشغّل، فلوحة الإدارة، ثم الأفلام، فالمسلسلات والحلقات، فالاشتراكات، فالمفضلة وسجل المشاهدة، فالأمان، ثم الأوبتيميزيشن، ثم النشر. لا تحذف أي ميزة موجودة أثناء إضافة ميزات جديدة. وفي النهاية، تأكد أن البناء يكتمل بنجاح بدون أخطاء. ابدأ التنفيذ الحقيقي الآن من المرحلة الأولى، وأنشئ الملفات الفعلية للمشروع، وليس مجرد شرح.
